# `technical-glossary/` — Glossário técnico

Glossário **cumulativo** dos termos técnicos introduzidos em cada capítulo do livro-texto. Cresce ao
longo do semestre e, ao final, consolida os principais conceitos utilizados na implementação de
modelos de linguagem.

O glossário **não é uma tradução** de termos em inglês. O propósito é registrar de forma sintética o
significado de cada termo e, principalmente, a **função que ele exerce dentro do modelo de linguagem**.

## Formato de cada entrada

Sempre que aplicável, uma entrada deve apresentar:

- **Termo original** (em inglês)
- **Tradução ou equivalente técnico** em português
- **Definição**
- **Função no modelo de linguagem**
- **Relação com outros conceitos**
- **Exemplo** conceitual, matemático ou computacional

## Organização

Um arquivo por capítulo, nomeado como `capitulo-NN.md` (ex.: `capitulo-01.md`), mantendo as entradas
em ordem alfabética dentro de cada arquivo.

## Critério de avaliação

O glossário é avaliado quanto à **precisão conceitual**, à **terminologia adequada** e à **relação dos
conceitos com a arquitetura estudada** — e compõe, junto às implementações intermediárias, 25% da nota
do projeto.
